# RPG 版核心企劃

> 狀態：初稿｜用途：確認遊戲方向與第一個可玩章節的範圍，不代表已定案的正史或實作規格。
>
> 本企劃沿用上層 CCG 專案的世界設定作為參考；不修改、不搬移 CCG 檔案。RPG 網頁需要的素材副本放在本資料夾 `assets/`，原始素材留在原位。

## 1. 一句話提案

在下一次元素潰堤到來前，玩家扮演能與七大神獸共鳴的凡人調律者，帶領一支冒險隊伍穿越受災地區；有限的行動、同伴信任與陣營選擇，決定誰能獲救、哪種力量被採用，以及世界將以何種代價撐過危機。

## 2. 版本定位

- 類型：單人劇情養成 RPG，含事件選擇、隊伍關係與章節戰鬥。
- 核心樂趣：在時間與資源有限時做取捨；逐步認識理念互相衝突的人；讓先前選擇在危機與結局中產生可見後果。
- 節奏參考：以短週期行動管理、事件旗標、人物關係和多結局構成重玩動機。參考《活俠傳》的設計感受，不直接複製其角色、文本、世界設定或專有表現。
- 與 CCG 的關係：共享 IP 設定的獨立玩法方向。卡牌對戰可作為原型素材或可選戰鬥表現，不是 RPG 必須沿用的核心循環。

## 3. 設計支柱

1. **選擇會留下痕跡**：重要選擇改變人物信任、陣營立場、可用支援或危機結果；不只改變一句回應。
2. **養成反映角色作風**：玩家以行動形成調律者的能力傾向，例如穩定、洞察、共鳴與交涉；能力用於開啟方案，不以單一數值判定好壞。
3. **同伴有自己的立場**：隊員會支持、質疑或拒絕玩家的作法；關係透過共同事件和承擔代價建立，不只靠送禮加好感。
4. **危機有期限**：探索與休整都占用有限行動，讓「做什麼」同時意味著「放棄什麼」。
5. **戰鬥服務於故事**：遭遇戰呈現選擇造成的準備差異、保護對象與代價，不以大量重複刷戰為主。

## 4. 玩家角色與故事前提

玩家是凡人「星幽調律者」，能與七大神獸共鳴。第一章沿用現有序章「潰堤前夜」與星界堤防即將失穩的危機：一處界碑周邊出現異常，當地倖存者面臨撤離、隔離或留下修復的抉擇。玩家受託與一支冒險隊伍調查異常，必須在危機擴大前決定如何處置。

調律者目前沒有已定案的出身、個人困境或發言風格。第一章應先讓玩家用選項塑造其態度（例如務實、同理、好奇），而非預設完整固定人格。初稿建議把「元素繫牌」視為調律者引導共鳴的工具或技藝，避免和世界觀文件中「凡人調律者」的定位產生另一個互斥身分；正式稱呼待企劃確認。

### 第一章核心問題

> 當封住裂隙會犧牲一部分人、而嘗試救援可能讓整個防線失守時，玩家願意承擔哪種責任？

此問題把世界設定中的三種理念轉成玩家可感受到的衝突：絕對制裁傾向消除威脅、原初守護傾向保住生命與平衡、深淵鎮守者則可能提出讓痛苦與失控能量歸於安息的方案。第一章不必讓三方都正式登場，可先透過命令、情報或隊員觀點呈現理念差異。

## 5. 核心遊戲循環

**進入章節危機 → 查看線索與隊伍狀態 → 分配有限行動 → 觸發事件與關係變化 → 準備並處理遭遇 → 面對章末抉擇 → 結算後果並推進主線**

建議垂直切片使用「章節日程」而非直接照搬月曆：每個章節分成數個行動時段，玩家每時段選一項行動，部分主線事件會推進危機。具體時段數先由切片測試再定，不先鎖死遊戲天數。

章節內容製作原則：每章至少安排四個有敘事回饋的選擇階段，例如抵達與立場、調查或準備、危機處置、後果取捨。階段數計算的是玩家面對不同情境並作出決定的場面，不是同一畫面上按鈕的數量；下一章入口的選擇另計。

### 可選行動原型

| 行動 | 可能收益 | 可能代價／取捨 |
|---|---|---|
| 勘查界碑與裂隙 | 線索、洞察、開啟安全方案 | 消耗時段，隊伍可能遭遇危險 |
| 協助撤離與安置 | 倖存者支援、守護者信任 | 少了調查或訓練時間 |
| 訓練調律能力 | 戰鬥手段或技能檢定提升 | 不直接改善關係或危機資訊 |
| 與隊員同行 | 解鎖個人觀點、信任與支線能力 | 限定同行者，錯過另一活動 |
| 交涉陣營代表 | 支援、通行權或替代解法 | 可能欠下人情或暴露立場 |
| 休整 | 恢復隊伍狀態、觸發營地對話 | 危機時鐘可能前進 |

## 6. 成長、關係與事件規則

### 調律者能力

首版只需 3–4 項可讀、可用於選項的能力，建議原型為：

- **共鳴**：穩定或引導元素力量，影響特殊解法與戰鬥技能。
- **洞察**：理解裂隙、界碑及事件線索，辨認風險。
- **交涉**：取得他人合作、協調不同立場。
- **堅忍**：在負荷或危險行動中維持狀態、承受代價。

能力值不應直接等同人格。玩家的對話與重大決策另記為少量旗標，例如「優先救人／優先封鎖」、「信任隊伍／依賴使者命令」，避免堆疊大量隱藏數值。

### 同伴關係

每位可發展同伴先用「信任」等單一可見軸；重大選擇再用事件旗標記錄價值觀是否一致。關係門檻可開啟同行技能、私人事件或替代選項，但不保證每次都能說服對方。首個切片只深入刻畫 2–3 位同伴。

### 事件資料最小欄位

事件需有：觸發條件、場景與角色、選項、能力／關係／危機影響、後續旗標、失敗或略過時的處理。重要分支要能在後續章節回收；一般對話可只改變回應，不必全部分岔成獨立劇情線。

## 7. 戰鬥方向

RPG 戰鬥的定位是「少量、具情境、由準備與選擇改變難度的遭遇」。首個切片先驗證一場短戰鬥：保護撤離隊伍、穩住裂隙或擊退失控眷屬，至少一項目標不只是消滅敵人。

候選方案為小隊回合制：玩家控制調律者與 1–2 位同行者，每回合選擇攻擊、防護、支援或使用元素共鳴；先前勘查、同伴信任與章末方案會影響可用技能或戰場條件。七元素與神獸羈絆保留為辨識度來源。是否採用卡牌抽取、資源支付或傳統技能指令，留待紙上原型比較後決定。

## 8. 第一章垂直切片

### 章名與目標

暫名沿用現有「第一章：潰堤前夜」。切片目標是在短流程內驗證：有限行動是否帶來有意義的取捨、角色是否有吸引力，以及章末選擇能否改變結果。

### 流程草案

1. **抵達**：展示界碑異常與撤離中的居民；玩家選擇初始態度，認識同行隊伍。
2. **調查／行動時段**：玩家從勘查、協助撤離、訓練、交涉、陪伴隊員中選擇有限次數的行動。
3. **資訊衝突**：查明裂隙不是單純擴大；封鎖、穩定與引導能量各有風險，隊員對優先次序意見不同。
4. **遭遇戰**：裂隙失控，玩家需在保護居民、穩定界碑或快速擊退敵人之間分配行動；前期準備影響可選策略。
5. **章末決策**：選擇先封鎖、先撤離後穩定，或冒險引導能量。每條路線都付出代價，並改變居民狀況、隊伍信任與下一章可用支援。
6. **結果場景**：讓玩家看見後果，記錄章節旗標並留下下一章鉤子。

### 切片內容上限

- 1 個主要地點、1 個核心危機、1 場戰鬥。
- 2–3 位重點同伴；其餘角色只作背景或短暫露面。
- 3–5 個行動選項、約 4–6 個主要事件節點、至少 3 種可辨識的章末結果。
- 2–4 項角色能力、少量關係與劇情旗標。
- 先以一張原創界碑村場景背景和三位同伴的透明立繪製作圖畫版垂直切片，驗證場景、對話與選擇的呈現；不先投入大量插圖、表情差分、配音或龐大內容量。

### 初步成功條件

- 玩家能說明本章的時間壓力及自己放棄了什麼。
- 至少兩種前期安排能在戰鬥或章末選擇中產生可見差異。
- 同伴的立場差異能從行動與反應看出，而不只靠人物簡介。
- 章末結果彼此有代價差異，並留下可延續的狀態。
- 玩家願意為了解其他角色反應或結果再玩一次。

## 9. 初稿假設與待定決策

以下均為待驗證提案，不視為既有正史：

- 第一章危機發生於原初守護防線附近，古龍遺跡隊伍可作為首選同伴群；星霄聖海可作後續路線、支援方或另一切片。
- RPG 以章節時段管理時間，並非逐日模擬；主線節點推進危機時鐘。
- 敘事選擇與短回合制小隊戰鬥共同構成玩法，卡牌形式尚未決定。
- 玩家可透過選項塑造主角性格；主角出身與固定台詞尚未定案。
- 需要統一現有資料中「星幽調律者」與序章「最後一位元素繫牌者」的稱呼和設定。
- 需要確認本作是否保留「與潰堤使徒討伐戰」作為章節主軸，或改成具有多方行動者的災害與政治衝突。
- 需要選定首章同行角色，並補上其性格、欲望、恐懼、彼此關係及個人事件。
- 需要確定玩家可否死亡／失敗、是否有永久損失，以及多週目如何提供新資訊或新選項。
- 需要確定目標平台、文字量、製作人力與可接受的內容規模，再選技術架構。
