# 第二章製作規格：星盤逆轉

> 狀態：原型劇情提案。第二章新增的觀星台、界碑危機與回聲線索均為 RPG 新內容，後續可依世界觀統整調整。

## 章節目的

承接第一章的三類決定，讓玩家看見撤離、封鎖或回應回聲造成的不同起點；再把各入口帶進同一個新地點，呈現危機已沿著界碑網絡擴散。第二章由入口安排、觀星台危機、危機後取捨與第三章序幕構成，讓選擇留下可接續的隊伍目標。

## 核心情境

隊伍循著東北方的星幽脈動抵達北方舊觀星台。中央界碑沒有破裂，但它接收的方向被某種力量折回自身，觀星台的星盤開始逆轉。山路上有巡守與迷途居民靠近；界碑裂痕則隨時間擴大。章末後，隊伍會依危機結果進入第三章的三種開場之一。

## 第一章入口回收

| 第一章結果 | 第二章開場 | 帶入的壓力 |
|---|---|---|
| 封鎖界碑 | 英格瓦守線，追查封印敲擊 | 封印內側的逆向脈動也在觀星台出現 |
| 撤離優先 | 弗蕾亞帶倖存者尋找水與藥 | 收容壓力迫使隊伍考慮安置與接應 |
| 成功理解回聲 | 法芙娜循線北行 | 有方向的訊息在觀星台變得斷續 |
| 未能理解回聲 | 調律者承受餘震，英格瓦陪同 | 界碑與調律者脈搏共振，接觸有額外負荷 |

各入口先選一項符合當前狀況的安排，再共同遭遇「星盤逆轉」。這些入口選項會透過文字、同行者和狀態目標體現第一章的不同後果。

第二章正式流程至少包含四個選擇階段：**入口安排 → 路線調查 → 危機處置 → 危機後取捨**。第三章序幕的第一個行動選擇另計，不拿來充第二章的階段數。

## 章內節點

1. **抵達觀星台**：依第一章結局呈現不同隊伍狀況，找到中央界碑。
2. **入口安排**：追查封印、加固防線、整理收容點、尋找物資、追蹤回聲、保存訊息、尋找調律錨點或請求守護者檢查。
3. **星盤逆轉**：界碑收到的回聲折回自身，山路上出現求援燈火；入口路線提供不同線索與角色反應。
4. **危機抉擇與後果場景**：穩住界碑、先接應山路上的人，或回應逆向脈動；依選擇呈現完整事件場景。
5. **危機後取捨**：留下記錄或立即追訊號；護送傷者或追最後燈火；先找調律錨點或循座標前進。
6. **第三章入口**：進入霜環峽、斷橋另一端或盲星谷，閱讀序幕並選擇第一個行動方向。

危機調查逐步揭露：封印敲擊與觀星台的逆轉屬於同一組界碑回響；它們不是從單一裂隙傳來，而是有人正在逐座改寫界碑收到的方向。回聲成功理解時，訊息留下「尚未校正」的片語；未能理解時，調律者的手臂成為回聲尋路的媒介。章末只確認有外力介入，不先揭露操作者身分。

## 章末狀態與第三章鉤子

- `chapterTwoEntryChoice`：入口安排，用於記錄玩家如何承接第一章狀態。
- `chapterTwoOutcome`：`steady`、`rescue` 或 `answer`，標記本章危機方案。
- `nextGoal`：供下一章開場接續的明確行動目標。
- **穩定界碑**：觀星台暫時恢復指北，遠方仍有規律回應。
- **接應倖存者**：救援成功但界碑裂痕擴大，東側山道中斷。
- **回應脈動**：取得陌生界碑座標，調律者負荷加深且回聲不只一個。

第二章的危機解法與危機後取捨會組合成第三章開場：穩定界碑導向「霜環峽的無星夜」，救援導向「斷橋另一端」，回應回聲導向「盲星谷的座標」。每個入口都已提供序幕、角色對話、場景細節和兩個第一行動選項；選完後記錄第三章目標並停在第三章正式內容之前。

## 待延伸

目前原型以一張主場景插畫呈現觀星台段落，第三章入口文字會依三種危機結果切換。後續可為霜環峽、斷橋與盲星谷補上各自的場景插圖，並延伸第三章正式事件流程。
