# 第四章失敗結局支線：兩條路盡頭的失城

## 接入點

支線從「倒懸之城的心臟」開始。原有「重啟核心，讓維洛斯回到星圖」與「切斷核心與星圖的連結」兩條路線及結局保持原樣；新增的「把核心力量分給兩條路」會同時啟動互斥的定位，造成城市失去穩定座標。

## 節點流程

所有節點只有一個選項，確保此支線必定抵達失敗結局。

1. **兩種方向的心跳**（核心失序）：固定六道光環，震動傳入全城。
2. **翻轉的城門**（撤離城門）：帶居民穿過最後光橋，橋斷後隊伍留在城內。
3. **空座上的最後座標**（最後座標）：以同行者記憶固定城市輪廓，座標落入星圖空白。
4. **星圖之外的維洛斯**（星圖之外）：將定位光交給撤離者，城市座標徹底消失。
5. **兩條路盡頭的失城**（失敗結局）：居民安全，城市無法定位或返回；成功的撤離代價超出隊伍承受範圍。

支線使用獨立 phase，存檔續玩、進度索引、章節故事紀錄與場景背景都會辨識新增節點。失敗結局沒有前往第五章的按鈕；玩家可重看結局或開始新週目。
