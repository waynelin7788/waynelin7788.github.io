# 隱藏結局解鎖紀錄（劇透）

> 開發者備忘：此文件記錄隱藏結局的正式條件，供日後維護劇情與程式使用。若把 RPG 專案公開給玩家，這份文件會揭露彩蛋解法。

## 結局資料

- 結局名稱：**群星共記的真名**
- 星噬者真名：**阿斯忒洛斯**（目前採用的故事設定）
- 專屬背景：`assets/scenes/undercity-ending-shared-stars.png`
- 專屬真名形態立繪：`assets/characters/asteros-true-form.png`；只在這個結局的尾聲場景取代一般星噬者立繪，不加入常駐角色面板。
- 唯一揭露真名的結局：只有此結局文字會寫出「阿斯忒洛斯」。其他結局只使用「星噬者」或「自己的名字」等稱呼。

## 解鎖條件

三項狀態必須同時達標：

- 失星航路證據 `undercityRouteEvidence >= 2`
- 失星航路信任 `undercityRouteTrust >= 3`
- 居民自主度 `undercityRouteCivilians >= 3`

達成後，「把真名寫進眾星共守的航路」會出現在第十章名字回廊節點；如果走「發出最後的潮汐訊號」，則會出現在最終結局選項中。未達成時此選項隱藏。

條件程式位於 `src/main.js` 的 `canUnlockUndercityTrueNameEnding()`。調整門檻、狀態累積方式或入口時，請同步更新本文件。

## 目前取得機率估算

程式沒有隨機判定，解鎖取決於玩家選擇。若假設相關二選一都以 50% 機率選擇：

- 已進入失星航路篇：**75%（3/4）**。第五章潮渠選擇與第十章「發訊／潛入」的四種組合中，三種符合條件。
- 從頭開始：**37.5%（3/8）**。還需在第四章選擇切斷維洛斯與星圖的連結，才能進入失星航路篇。

這是等機率假設下的理論估算；玩家偏好的選擇會改變實際比例。目前門檻屬於隱藏路線，尚未達到極低機率的彩蛋難度。

## 若要提高稀有度

可將證據門檻提高為 `undercityRouteEvidence >= 3`。這會要求玩家先在第五章搶修航標、於第六章校準航線，並在第十章選擇潛入潮心：

- 已進入失星航路篇：**25%（1/4）**
- 從頭開始：**12.5%（1/8）**

這項提高稀有度的建議尚未套用到程式；目前實際門檻仍是證據至少 2、信任至少 3、居民自主度至少 3。

## 後續特殊結局的紀錄準則

未來若新增需要特定機制條件才能抵達的結局，請沿用本文件格式，至少記下：

1. 結局名稱、劇情結果、專屬素材，以及是否包含唯一資訊（例如角色真名）。
2. 完整解鎖條件、相關狀態欄位、狀態由哪些選擇累積，以及選項出現在哪個節點。
3. 在程式中的判斷位置，避免文件條件與實際邏輯逐漸不同。
4. 取得機率的估算假設，分別說明已進入該路線與從頭遊玩的比例；若選擇並非等機率，標明這只是理論值。
5. README 或玩家文件是否揭露條件。預設只在 README 標示「含劇透」的設計紀錄連結，不在一般遊玩說明公開解法。

每次調整結局條件、狀態來源、選項顯示或機率估算，都要同步更新此設計紀錄。特殊結局若需要極低取得率，先用可達路線枚舉條件組合，再決定門檻，不以「隱藏」本身推定它已經稀有。
