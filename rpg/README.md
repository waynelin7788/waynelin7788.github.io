# 星幽啟示錄：元素潰堤 RPG 版

此資料夾供 RPG 版獨立規劃與開發使用。現有 CCG 原型及其文件、資料與素材維持原位，不在此階段搬動或修改。

## 版本定位

- 本資料夾：RPG 版
- 上層專案：現有 CCG 原型
- 世界觀、角色與素材：RPG 版可引用上層既有素材；原始檔留在原位，網頁需要的輕量圖片副本放在本資料夾 `assets/`，便於獨立放上 GitHub Pages。

## 建議內容

- `docs/`：RPG 設計、劇情、角色關係與章節文件
- `data/`：事件、角色狀態、路線與結局資料
- `src/`：RPG 版程式
- `assets/`：RPG 專用或經確認可共用的素材

## 目前文件

- [RPG 版核心企劃](docs/core-concept.md)：版本定位、核心循環、成長與關係、戰鬥方向、第一章垂直切片及待定決策。
- [第一章事件流程與核心同伴](docs/chapter-one-flow.md)：原型事件節點、同伴動機提案、狀態欄位與平衡原則。
- [第一章製作規格](docs/chapter-one-spec.md)：同伴人物卡、旗標回收、章末方案、戰鬥與技術方向，以及下一個製作里程碑。
- [第二章製作規格](docs/chapter-two-spec.md)：四種第一章承接入口、觀星台主線危機、後果取捨，以及通往第三章的三種序幕入口。
- `data/chapter-content.js`：第一章完整流程，以及第二章連續事件、後果選擇、第三章序幕與首個行動方向。
- [開啟網頁原型](index.html)：可直接在瀏覽器中遊玩第一章流程。

## 網頁試玩

本原型是純靜態網頁，入口為 `index.html`，沒有建置步驟、伺服器或外部套件依賴。第一章以劇情插畫、角色立繪、場景對話和狀態面板呈現；所需圖片已放在 `assets/`，因此整個 RPG 資料夾可以獨立部署。事件文字與分支集中在 `data/chapter-content.js`；進度會自動存入目前瀏覽器，並提供三個手動存檔位保存不同故事線。存檔卡以「章－段－最近分歧」顯示進度索引，實際續玩則使用包含選擇、角色狀態與故事紀錄的完整快照。「故事紀錄」也能下載為 UTF-8 `.txt`，供閱讀回顧；此文字檔不包含可還原的遊戲狀態。可先直接用瀏覽器開啟檢視；要分享給朋友時：

1. 建立一個專用 GitHub 儲存庫。
2. 將本資料夾裡的檔案與子資料夾放到儲存庫根目錄（讓 `index.html` 位於根目錄）。
3. 在儲存庫的 **Settings → Pages**，選擇從分支發佈，分支選 `main`、資料夾選 `/(root)`，然後儲存。
4. 等待 GitHub Pages 發佈完成後，把頁面網址分享給朋友。

GitHub Pages 可從指定分支的根目錄發佈靜態網站；官方說明見[設定發佈來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。網站會公開在網際網路上，請勿放入私人資料。

若把本資料夾留在另一個儲存庫的子資料夾，GitHub Pages 的分支來源選項不能直接指定任意子資料夾，需另加 Actions 部署設定。

第一章圖畫版的小樣使用獨立生成的「界碑村黃昏」場景背景，以及參照上層角色原圖生成的英格瓦、弗蕾亞、法芙娜透明立繪。第二章使用北方舊觀星台黎明遠景作共用劇情背景。網頁使用的輕量 WebP 圖片收在本資料夾 `assets/`；未使用的 JPG 與高畫質 PNG 原稿移至同層 `rpg-source-archive/`，不會隨 RPG 網頁部署。上層原始素材與 CCG 專案檔案維持不變，RPG 專案可獨立部署。

第一章戰鬥使用原創裂隙獸場景插畫（`assets/scenes/rift-beast.webp`），取代原先借用的元素神獸圖。
