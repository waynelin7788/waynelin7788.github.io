# 基礎卡牌類型整理

## 1. 資源 / 充能卡

英文：Resource / Energy Cards

用途：提供施放法術、召喚眷屬、發動技能所需費用。

子類型：

- 純粹晶體：對應特定元素的基本資源。
- 萬能稜鏡：可視為任意元素的通用資源，但通常有延遲使用或其他副作用。

設計重點：

- 資源節奏決定手機對局長度。
- 不同元素可以有不同資源個性。
- 通用資源應避免完全取代元素專屬資源。

## 2. 法術 / 戰技卡

英文：Spell / Action Cards

用途：打出後產生一次性效果。

子類型：

- 攻擊型：造成直接傷害。
- 防禦 / 控場型：減傷、凍結、護盾、延遲敵方攻勢。
- 檢索 / 濾牌型：抽牌、找出特定卡牌、準備神獸召喚。

設計重點：

- 適合承載元素個性。
- 手機端卡牌文字需簡潔。
- 關鍵戰技可與共鳴值互動。

## 3. 眷屬 / 召喚物卡

英文：Follower / Minion Cards

用途：在召喚神獸前建立場面、攻擊、防守與連鎖效果。

子類型：

- 前排護衛：高生命、低攻擊，常帶嘲諷或阻擋。
- 後排輸出：低生命、高攻擊，或帶持續增益。
- 消耗品：進場觸發一次性效果後自我毀滅，可作為祭品或連鎖材料。

設計重點：

- 可用前排 / 後排建立簡化戰線。
- 眷屬應提供不同元素的場面策略。
- 消耗品適合支援連鎖與共鳴爆發。

## 4. 場地 / 環境卡

英文：Field / Environment Cards

用途：改變對戰場域與全局規則。

子類型：

- 元素領域：例如雷暴區域、深海、大地堡壘。
- 覆蓋場地：雙方可用新場地覆蓋舊場地，形成領域爭奪。

設計重點：

- 通常全場只存在一張主要場地。
- 可支援領域支配式特殊勝利。
- 場地效果應清楚顯示，避免玩家忘記。

## 5. 階段 / 討伐事件卡

英文：Phase / Subjugation Events

用途：觸發大型戰局變化，讓對局具有首領戰般的戲劇性。

子類型：

- 戰局切換：滿足條件後進入特殊討伐階段。
- 狂暴機制：改變費用、傷害、生命壓力或回合節奏。

設計重點：

- 這類卡牌應稀有且具備強烈演出感。
- 效果要能推動對局終結，避免拖延。
- 適合與神獸型態、共鳴值、場地控制互動。
