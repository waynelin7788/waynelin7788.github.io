# 完整卡牌類型

牌組以一位元素使者為主將，正式建議 40 張。下列六類構成完整規則；目前瀏覽器原型主要呈現法術、冒險者、神獸與使者的簡化對戰效果，資源、場地和討伐事件尚屬資料與規則設計，尚未進入互動戰場。

## 1. 元素使者（主將卡）

牌組核心角色，具有第一階段與神獸融合第二階段生命，以及各自的被動和元素羈絆。七位使者由玩家於對局前選擇。

## 2. 資源／充能卡

支付施放法術、召喚眷屬和使用技能的費用。純粹晶體提供特定元素；萬能稜鏡可代替任意元素，通常帶有延遲或代價。通用資源不可完全取代專屬資源。

## 3. 冒險者與眷屬卡

建立戰線，提供攻擊、防守、治療、護佑或詛咒支援。職責包含前排護衛、近戰輸出、遠程輸出、遠程詛咒與治療護佑。新增兩隊的十名角色都屬於此類。

瀏覽器原型每局每名本隊冒險者只放入一張；對方小隊招募的外援也只放入一張。正式牌組的冒險者張數仍依牌組構築規則調整。

## 4. 法術／戰技卡

一次性效果，包括攻擊、防禦、控場、檢索和濾牌。法術可與共鳴、連鎖和隊伍特性互動。

## 5. 領域／環境卡

持續改變全場規則，例如雷暴區域、深海或大地堡壘。全場同時存在一張主要領域；新領域可覆蓋舊領域。部分領域可累積領域支配勝利進度。

## 6. 神獸與討伐事件卡

神獸在共鳴滿載或條件達成時登場，觸發元素羈絆。討伐事件則代表戰局切換或狂暴機制，稀有且應推動對局走向終結。
